Ток утечки PWRDWN/ALSB до +50 мкА, RESET ±10 мкА — подтяжки 10 кОм достаточны.

### 1.1 Питание (Table 1, стр. 4; UG-637 Table 89, стр. 62)

| Рельс | Пины | Диапазон | Ток тип. | Ток расчётный (UG-637) |
|---|---|---|---|---|
| DVDDIO | 2 | 2,97–3,63 В | 1,5 мА | 5 мА |
| DVDD | 3 | 1,71–1,89 В | 70 мА | 110 мА |
| AVDD | 21 | 1,71–1,89 В | 47 мА (CVBS) | 100 мА |
| PVDD | 16 | 1,71–1,89 В | 12 мА | 20 мА |
| MVDD | 13 | 1,71–1,89 В | 14 мА | 20 мА |
| **Итого 1,8 В** | | | **≈ 143 мА** | **250 мА** |

Абсолютные максимумы: 1,8 В-рельсы ≤ 2,2 В; DVDDIO ≤ 4 В; |PVDD−DVDD|, |MVDD−DVDD|, |AVDD−DVDD| ≤ 0,9 В (Table 7).
Тепло: θJA = 32,5 °C/W на 4-слойной плате с EP на земле (Table 8).

**Развязка (UG-637 «Power Supply Decoupling», стр. 61, Fig. 44):** у каждого вывода питания — 0,1 мкФ + 10 нФ, в пределах ≈ 0,5 см,
на той же стороне платы, что и чип; ток идёт «плоскость → конденсатор → пин», via под площадкой 100 нФ к плоскости питания.
PVDD — отдельная фильтрация; желательно раздельные регулируемые источники для AVDD/PVDD и DVDD/DVDDIO. Один общий земляной полигон.

### 1.2 Аналоговый вход (даташит Fig. 9, стр. 16; UG-637 Fig. 8, стр. 12)

Разъём → внешний ESD → 24 Ω последовательно → 100 нФ → AIN1; 51 Ω на землю после 24 Ω.
24 + 51 = 75 Ω терминация, делитель 0,68, вход до 1,47 В p-p. Дорожки — минимальной длины, по возможности 75 Ω.
Чип ESD < 2 кВ (HBM) → внешняя защита обязательна (низкоёмкостной TVS/диод).

### 1.3 Кварц (даташит Table 6, стр. 9; AN-1260)

28.63636 МГц, **фундаментальная мода**, стабильность ±50 ppm суммарно (AN-1260 Table 1: калибровка ±30 ppm, температурная ±50 ppm, ESR ≤ 30 Ω, drive 100 мкВт, C0 ≤ 7 пФ).
Нагрузочные конденсаторы по AN-1260: `C1 = C2 = 2·(CL − CS) − CPG`, где CS (паразитная ёмкость платы) 2–3 пФ, CPG (пин–земля) 4–10 пФ.
Пример AN-1260: CL = 30 пФ → 47 пФ. Для SMD-кварца с CL = 18 пФ → 2·(18−3)−4 = 26 → **27 пФ**; CL = 20 пФ → 33 пФ. Значение фиксируется на этапе 1 по выбранному кварцу.

### 1.4 MIPI CSI-2 Tx (даташит Table 3/4, стр. 6–8; UG-637 стр. 55, 61)

* 1 лента данных (D0P/D0N) + клок (CLKP/CLKN). Скорость: **216 Мбит/с** interlaced (по умолчанию), 432 Мбит/с progressive (I2P).
* HS-swing 140–270 мВ, common-mode 150–250 мВ; LP-режим на blanking-интервалах — пары работают и как дифференциальные, и как одиночные.
* UG-637: дорожки **максимально короткие, на той же стороне, что чип**, сплошная опорная (земляная) плоскость в соседнем слое;
  **каждая пара — две слабо связанные 50 Ω одиночные линии** (loosely coupled) → цель: 100 Ω дифф при ~50 Ω SE.
* Внутрипарное выравнивание ≤ 0,1 мм, межпарное ≤ 1 мм (ТЗ); UI при 216 Мбит/с = 4,6 нс — требования нежёсткие, но соблюдаем.
* Без переходных отверстий на MIPI-парах.

### 1.5 I²C (Table 6, Table 15)

≤ 400 кГц. Адреса (8-бит): ALSB = 0 → 0x40/0x41; ALSB = 1 → 0x42/0x43. Подтяжки к 3,3 В на плате Pi уже есть (официальная документация: «SCL and SDA are pulled up to 3.3 V on the Raspberry Pi board»; номинал по reduced-схеме не читается);
на плате — дополнительно 2,2–4,7 кОм (по ТЗ) через перемычки/опционально. Уровень 3,3 В (DVDDIO).

### 1.6 Сброс / Power-down

* RESET: активный низкий, ≥ 5 мс. Достаточно RC-цепи от 3,3 В (например 10 кОм / 1 мкФ → τ = 10 мс) + кнопка/тестовая точка.
* PWRDWN: низкий = power-down; I²C работает и в power-down. Драйвер может использовать `powerdown-gpios`, но overlay Pi их не задаёт (см. §3).

## 2. Разъём камеры Raspberry Pi 4 (J3, 15 конт., шаг 1,0 мм)

| Пин | Сигнал Pi 4 | Описание | На нашей плате |
|---|---|---|---|
| 1 | GND | | GND |
| 2 | CAM1_DN0 | D-PHY lane 0 − | D0N (пин 10 чипа) |
| 3 | CAM1_DP0 | D-PHY lane 0 + | D0P (пин 9) |
| 4 | GND | | GND |
| 5 | CAM1_DN1 | D-PHY lane 1 − | NC (1 лента) |
| 6 | CAM1_DP1 | D-PHY lane 1 + | NC |
| 7 | GND | | GND |
| 8 | CAM1_CN | D-PHY clock − | CLKN (пин 12) |
| 9 | CAM1_CP | D-PHY clock + | CLKP (пин 11) |
| 10 | GND | | GND |

| 12 | CAM_IO1 | на Pi 4 **не подключён** (на схеме NC) | NC |
| 13 | SCL0 | I²C SCL (3,3 В, подтянут на Pi) | SCLK (пин 31) |
| 14 | SDA0 | I²C SDA | SDATA (пин 30) |
| 15 | 3V3 | питание 3,3 В | вход питания платы |

Особенности Pi 4:
* SCL0/SDA0 разъёма камеры — это шина `i2c0` через мультиплексор `i2c0mux` на **GPIO44/GPIO45** (`bcm283x-rpi-i2c0mux_0_44.dtsi`, канал 1 = `i2c_csi_dsi`), а не GPIO0/1 (те же контроллер, разные пины; GPIO0/1 = ID_SD/ID_SC на 40-pin). Пользователю ничего настраивать не нужно — overlay включает `i2c0if`/`i2c0mux`.
* Разъём CSI на Pi 4 — 2 ленты (`bcm283x-rpi-csi1-2lane.dtsi`), используем одну.
* Нумерация разъёма модуля камеры v2.1 совпадает с J3 Pi (1:1): J1 pin 3 = CSI_D0P, 9 = CLKP, 13 = SCL, 14 = SDA, 15 = 3V3. Наша плата повторяет разъём модуля камеры (см. `assumptions.md` A0-5).
* Ориентация шлейфа на Pi 4: «контакты в сторону от защёлки» (официальная документация).

## 3. Device tree overlay `adv728x-m` (Raspberry Pi kernel `rpi-6.12.y`)

`adv728x-m-overlay.dts` — обёртка над `adv7282m-overlay.dts`; параметр `adv7280m=1` меняет `compatible` на `adi,adv7280-m`.

Что overlay задаёт:
* узел `adv728x@21` на `i2c_csi_dsi`, **`reg = <0x21>`** (7-бит) — т. е. 8-битный адрес записи **0x42 → ALSB = 1**. Параметр `addr=` позволяет переопределить.
* `clock-frequency = <24000000>` (для драйвера не критично), endpoint: `clock-lanes = <0>`, **`data-lanes = <1>`** (одна лента), `link-frequencies = 297 MHz`.
* `csi1` включён, `compatible = "brcm,bcm2835-unicam-legacy"` (если не `media-controller=1`).
* `i2c0if`, `i2c0mux` — `status = "okay"`.

Чего overlay **не задаёт** (проверено по `adv7282m-overlay.dts` и драйверу `adv7180.c`, строки 1517–1531):
* `powerdown-gpios`, `reset-gpios` — драйвер берёт их через `devm_gpiod_get_optional`; при отсутствии — не трогает; сброс выполняет программно (рег. 0x0F[7]).
* регулятор `cam1_reg` (CAM_GPIO) — **не** включается, поэтому уровень пина 11 не гарантирован (скорее всего низкий, т. к. ядро отключает неиспользуемые регуляторы).

**Вывод для схемы:** чип должен быть в рабочем состоянии сразу после подачи 3,3 В без участия Pi:
PWRDWN → подтяжка к 3,3 В; RESET → RC к 3,3 В (≥ 5 мс); ALSB → 3,3 В (адрес 0x21) — с перемычкой на GND (тогда `addr=0x20`).
CAM_GPIO — только через опциональные перемычки. Строка config.txt: `dtoverlay=adv728x-m,adv7280m=1`.

## 4. Печатная плата

* 4 слоя, стек JLCPCB **JLC04161H-7628**: Cu 35 мкм (внешние) / prepreg 7628 0,2104 мм, εr 4,4 / core ~1,065 мм εr 4,6 / prepreg 7628 / Cu; итого 1,6 мм. Слои: L1 сигналы+чип, L2 **сплошная земля**, L3 питание (3,3 В / 1,8 В полигоны), L4 сигналы/земля.
* MIPI 100 Ω дифф на L1 над L2: предварительно **w ≈ 0,18–0,20 мм, s ≈ 0,15 мм** (оценка по микрополосковым формулам; финально — калькулятор JLCPCB на этапе 3). 50 Ω SE ≈ 0,35 мм.
* Аналоговый вход и кварц — вплотную к чипу (AIN1 — пин 17, XTAL — пины 14/15: правая/нижняя стороны корпуса), MIPI — пины 9–12 (нижняя сторона), I²C/RESET/PWRDWN/ALSB — пины 28–32 (верх). Разъём CVBS на одной кромке, FFC — на противоположной; LDO вдали от входа и кварца.
* Термопад 32-LFCSP: массив via на землю (L2).
* Все компоненты с одной стороны (верх); при необходимости 10 нФ у чипа снизу — нежелательно по UG-637 (индуктивность via).

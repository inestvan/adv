# Размеры платы для корпуса (rev C, кейс СПРУТ-2)

Система координат: вид сверху (сторона компонентов), начало — левый верхний угол платы, X вправо, Y вниз, мм.
В DXF (`board-outline.dxf`, `board-top-fab.dxf`) ось Y направлена вверх (стандарт CAD): Y_dxf = −Y_таблицы.
`board.step` — плата с 3D-моделями компонентов из библиотек KiCad 10 (у U1, J1 и D3 своих моделей нет — в STEP их нет,
высоты — в таблице ниже).

## Плата

| | мм |
|---|---|
| Габарит | 42,0 × 55,0, толщина 1,6, углы R1,5 |
| Секция декодера | Y = 0…32 (после отлома 42 × 32) |
| Паз | Y = 32…34 во всю ширину; перемычки X = 7,0…9,5 и 31,15…33,65; через правую идёт видеодорожка |
| Секция буфера THS7314 | Y = 34…55 (после отлома 42 × 21) |
| После отлома | перемычки перекусить кусачками, края зачистить надфилем; кромки у паза плоские |

## Крепёжные отверстия Ø 2,2 (M2, без металлизации; вокруг Ø 5 свободно)

| | X | Y |
|---|---|---|
| H1 (декодер) | 8,0 | 3,2 |
| H2 (декодер) | 39,5 | 27,5 |
| H3 (буфер) | 3,2 | 51,8 |
| H4 (буфер) | 39,5 | 37,0 |

У каждой секции по два отверстия по диагонали: после отлома каждая крепится сама. Если плата целая — все четыре.

Стойки под платой: ≥ 3 мм (снизу торчат только капли пайки проводов ≈ 1 мм). Снизу компонентов нет.
Для печатного держателя на `module_plate`: 4 бобышки Ø 5 под саморез M2 (отверстие в бобышке Ø 1,6–1,7) высотой ≥ 3,5.

## Разъёмы и куда выходят кабели

| Элемент | Кромка | Положение | Что нужно в корпусе |
|---|---|---|---|
| J2 «CVBS» / J8 «TO ADV» (площадки под пайку коаксиала, отверстия Ø 1,0) | у паза справа | J2: (32,4; 28,5) сигнал, (34,94; 28,5) GND; J8: (32,4; 35,8) сигнал, (34,94; 35,8) GND | только при разделённых секциях; кабель паять сверху, закрепить стяжкой или клеем |
| J1 шлейф камеры (FFC 15 конт., 1,0 мм) | левая (X = 0) | центр Y = 15,0; корпус разъёма Y = 6,1…23,9, X = 0…5,5; высота 3,0 (замок открыт ≈ 5,5) | свободный выход шлейфа влево, доступ к замку сверху; радиус изгиба шлейфа ≥ 3 |
| J5 CVBS IN (площадки под коаксиал) | левый край | (6,7; 37,9) сигнал, (6,7; 40,44) GND | кабель припаян сверху; место под изгиб коаксиала (≥ 10 мм для RG-179) |
| J4 +5V (площадки под провода) | левый нижний угол | (3,5; 45,35) +5 В, (6,04; 45,35) GND | 2 провода 0,2–0,35 мм², припаяны сверху |
| J7 GX16 (площадки под коаксиал) | низ справа | (29,8; 48,3) сигнал, (32,34; 48,3) GND | кабель припаян сверху |
| J6 TV (площадки под коаксиал) | низ справа | (36,9; 48,3) сигнал, (39,44; 48,3) GND | кабель припаян сверху |

Разъёмов на плате нет: все площадки — металлизированные отверстия Ø 1,0 мм (шаг 2,54); кабели выходят вверх от платы,
в корпусе нужен зазор над площадками под изгиб кабеля и место для стяжки/клея.

## Высота компонентов над платой (верх)

| Зона | мм |
|---|---|
| FFC J1 | 3,0 (замок открыт ≈ 5,5) |
| Кварц Y1, LDO, SOIC THS7314, SS14 | ≤ 2,3 |
| Остальные SMD | ≤ 1,0 |

Самая высокая деталь — FFC J1 (3 мм, с открытым замком ≈ 5,5). Над площадками J2, J4–J8 — изгиб припаянных кабелей (заложить ≥ 8–10 мм для коаксиала).

## Прочее

* Тестовые точки TP1–TP9 и перемычки JP1–JP3 — площадки на верхней стороне; JP1–JP3 вдоль верхней кромки (Y = 2,7, X = 13,5 / 19,6 / 24,6).
* Чип U1 (20,0; 10,5) греется слабо (≈ 0,3 Вт), вентиляция не нужна; THS7314 ≈ 0,1 Вт.
* Шлейф камеры входит в J1 контактами вниз (к плате).

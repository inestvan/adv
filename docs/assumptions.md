# Допущения и открытые вопросы

Файл ведётся по ходу всех этапов. Каждое допущение помечено этапом, на котором возникло.
Статус: **OPEN** — ждёт решения заказчика, **ACCEPTED** — подтверждено, **CLOSED** — снято.

## Этап 0

| # | Допущение / вопрос | Статус |
|---|---|---|
| A0-1 | Сайт analog.com недоступен из среды разработки (обрыв TLS/503 на всех запросах). Даташит ADV7280 Rev. A, UG-637 Rev. A и AN-1260 Rev. 0 получены как **архивные копии оригинальных PDF с analog.com через web.archive.org** (`id_`-режим, байт-в-байт оригинал). Контрольные суммы записаны в `docs/requirements.md`. Копии с зеркал дистрибьюторов (Rev. 0 UG-637) удалены как более старые. | ACCEPTED (факт среды) |
| A0-2 | **I²C-адрес.** Overlay `adv7282m` (который включает `adv728x-m`) задаёт `reg = <0x21>` (7-битный адрес) = 8-битный адрес записи **0x42** = по даташиту **ALSB = 1 (лог. «1»)**. ТЗ требует ALSB на GND (0x40 write / 0x20 7-бит). Чтобы строка `dtoverlay=adv728x-m,adv7280m=1` работала **без параметра `addr=`**, ALSB должен быть подтянут к DVDDIO (3,3 В). Предложение: ALSB через перемычку (паяльную) — по умолчанию к 3,3 В (адрес 0x21), опционально на GND (0x20, тогда в config.txt нужно `addr=0x20`). | **DECIDED**: ALSB → 3,3 В через 10 кОм, паяльная перемычка на GND (по умолчанию разомкнута). Выигрыш: `dtoverlay=adv728x-m,adv7280m=1` работает без `addr=`; цена — один резистор и перемычка. |
| A0-3 | **RESET / PWRDWN.** Overlay `adv7282m` **не задаёт** `reset-gpios` / `powerdown-gpios`, а драйвер `adv7180.c` получает их как *optional* (`devm_gpiod_get_optional`) — при их отсутствии драйвер ничего не дёргает и делает только программный сброс по I²C (рег. 0x0F[7]). Overlay также **не включает** регулятор `cam1_reg` (CAM_GPIO, пин 11 разъёма, GPIO-экспандер Pi 4 линия 5), поэтому уровень CAM_GPIO при загрузке с этим overlay не гарантирован (ядро отключает неиспользуемые регуляторы → скорее всего **низкий**). Следствие: чип должен выходить из reset и power-down **аппаратно, без участия Pi**: PWRDWN и RESET — подтяжки к 3,3 В (RESET — RC-цепь ≥ 5 мс по даташиту). Перемычки для подключения CAM_GPIO к PWRDWN (и/или RESET) — опция, по умолчанию разомкнуты. | **DECIDED**: PWRDWN — 10 кОм к 3,3 В; RESET — 10 кОм / 1 мкФ к 3,3 В (τ ≈ 10 мс > 5 мс) + тестовая точка; две паяльные перемычки CAM_GPIO→PWRDWN и CAM_GPIO→RESET, по умолчанию разомкнуты. Выигрыш: работает со штатным overlay. Что теряем: Pi не может усыпить чип (≈ 250 мВт постоянно); при желании — замкнуть перемычку и включить `cam1_reg` в своём overlay. |
| A0-4 | Питание 1,8 В: типовой ток 1,8 В-рельс ≈ 143 мА (AVDD 47 + DVDD 70 + PVDD 12 + MVDD 14), расчётный по UG-637 табл. 89 — 250 мА. При одном LDO в SOT-23-5 (AP2112K, θJA ≈ 250 °C/W) рассеивание (3,3−1,8)·0,143 = 0,21 Вт → +54 °C типично, до +94 °C при расчётном токе — на грани. UG-637 рекомендует раздельные регуляторы для AVDD/PVDD и цифры. Предложение: **два LDO** — AMS1117-1.8 (SOT-223, JLCPCB Basic) на DVDD+MVDD и малошумящий LDO (AP2112K-1.8 или ME6211C18) на AVDD+PVDD с ферритами. Альтернатива: один LDO в SOT-223 + ферритовые бусины. | **DECIDED**: два одинаковых AP2112K-1.8TRG1 (Diodes, LCSC C176944, SOT-23-5, 600 мА, малошумящий): LDO1 → DVDD+MVDD (≈ 84 мА тип., 0,13 Вт), LDO2 → AVDD+PVDD (≈ 59 мА тип., 0,09 Вт). Выигрыш: тепловой запас ×2 и раздельное аналоговое питание по UG-637; цена +0,17 $ и два конденсатора, без дополнительной платы за extended-деталь (одна и та же позиция). В базовой библиотеке JLCPCB 1,8 В LDO нет вообще (проверено через API JLCPCB), поэтому extended неизбежен. |
| A0-5 | Разъём FFC на плате повторяет **разъём модуля камеры Raspberry Pi** (15 конт., шаг 1,0 мм, нижние контакты, на верхней стороне, у кромки, шлейф выходит наружу), нумерация 1:1 с J3 Pi (1 = GND … 15 = 3V3, подтверждено схемой Camera Module v2.1: J1 pin 3 = D0P, 9 = CLKP, 13 = SCL, 14 = SDA, 15 = 3V3). Предполагается стандартный 15-жильный шлейф камеры Pi (тот, что идёт с Camera Module). Нумерация выводов у разных производителей 15P/1.0 мм разъёмов может отличаться зеркально — **перед первым включением проверить мультиметром: 3,3 В должно приходить на пин 15, GND на пин 1**. | **CLOSED**: на Camera Module v2.1 стоит **Amphenol SFW15R-1STE1LF** (из официальной схемы, J1); он есть у JLCPCB — **C3168538**, 9 395 шт., 0,61 $. Ставим тот же разъём в той же ориентации (верхняя сторона, у кромки, шлейф наружу, контакты к плате) — совместимость со штатным шлейфом получается автоматически, без рассуждений о типе A/B. Проверка мультиметром перед первым включением остаётся хорошей практикой. |
| A0-6 | Используется только лента данных 0 (D0) и клок — `data-lanes = <1>` в overlay. Пины 5/6 (лента 1) разъёма оставляются неподключёнными. | ACCEPTED (следует из overlay) |
| A0-7 | Кварц: UG-637 и даташит не задают значения нагрузочных конденсаторов; используется методика AN-1260 (C = 2·(CL − CS) − CPG). Конкретный кварц выбирается из каталога JLCPCB на этапе 1, C1/C2 считаются под его CL (для CL = 30 пФ по AN-1260 → 47 пФ; для типового SMD-кварца CL = 18–20 пФ → ≈ 27–33 пФ). | ACCEPTED |
| A0-8 | Импеданс MIPI: предварительная оценка по формулам микрополоска для JLC04161H-7628 (h = 0,2104 мм, εr = 4,4): 100 Ω дифф ≈ 0,18–0,20 мм / зазор 0,15 мм. Финальные значения на этапе 3 сверяются с калькулятором JLCPCB. | ACCEPTED |
| A0-9 | KiCad 9.0.9 установлен из PPA `kicad/kicad-9.0-releases`; `kicad-cli sch erc` и `kicad-cli pcb drc` проверены на тестовых файлах. Стандартные библиотеки KiCad 9 (symbols/footprints) установлены. | ACCEPTED |
| A0-10 | **Наличие чипа.** ADV7280WBCPZ-M у JLCPCB — C662261, **склад 0** (цена в каталоге 3,94 $, вероятно устаревшая); все варианты ADV7280x-M на складе 0. Вариант с «WBCPZ-M-RL» (C662262) тоже 0. Для сборки нужно либо consignment (свои чипы, прислать в JLCPCB), либо JLCPCB Global Sourcing / предзаказ, либо самостоятельная пайка. На проектирование не влияет. | **DECIDED**: чип заказчик покупает и паяет сам (фен/трафарет). Следствия для проекта: U1 в BOM/CPL JLCPCB помечается DNP (сборка без чипа), в комплект выходных файлов добавляется трафарет (Gerber paste-слой, площадка термопада с сеткой паяльной пасты ≈ 50 % покрытия), пассивные компоненты 0603 везде, где не требуется близость к пину чипа (развязка у чипа — 0402). |

Если нужно ровно 24 Ω — заменить R1 на extended-позицию при заказе. | DECIDED |
| A1-2 | Кварц: YXC YSX530GA 5032 (C112564), CL = 20 пФ, ESR ≤ 40 Ω (у 3225-корпусов HELE ESR 50 Ω, AN-1260 просит ≤ 30 Ω — 5032 ближе всего из складских). Нагрузочные 27 пФ C0G (Fenghua C92670, extended; 27 пФ в Basic нет). | DECIDED |
| A1-3 | ESD на входе: TI TPD1E10B06DPYR (C48260), 12 пФ, ±30 кВ. Nexperia PESD5V0S1BL/S1UL отвергнуты — у них 35 / 150 пФ (проверено по даташитам). 12 пФ при 75 Ω даёт полюс ~180 МГц, для CVBS (6 МГц) незаметно. | DECIDED |
| A1-4 | RCA-гнездо в каталоге JLCPCB отсутствует. Посадочное место сделано по Multicomp Pro PSG01546 (Farnell 3029582): штырь 1,3×2,5 мм, два ушка 2,5×1,0 мм на расстоянии 10 мм, 8,8 мм от переднего края — это стандартный «китайский» угловой RCA 9,7 мм; J2 помечен Assemble=no (пайка вручную). | A1-5 | Конденсатор VREFP–VREFN: в даташите/UG-637 номинал не указан, только требование «максимально близко к чипу»; поставлено 100 нФ 0402 (как в референсных схемах ADV7180/ADV7280). | ASSUMED |
| A1-6 | Подтяжки I²C 4,7 кОм на плате параллельно подтяжкам Pi; суммарно ≥ 1,3 кОм → ток стока ≤ 2,5 мА, в норме I²C. | DECIDED |
| A1-7 | Подтяжки RESET/PWRDWN/ALSB 10 кОм (утечка ≤ 50 мкА → падение ≤ 0,5 В, VIH = 2,0 В соблюдён). RC на RESET 10 кОм/1 мкФ (τ = 10 мс, минимум 5 мс). | DECIDED |

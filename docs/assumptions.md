# Допущения и открытые вопросы

Файл ведётся по ходу всех этапов. Каждое допущение помечено этапом, на котором возникло.
Статус: **OPEN** — ждёт решения заказчика, **ACCEPTED** — подтверждено, **CLOSED** — снято.

## Этап 0

| # | Допущение / вопрос | Статус |
|---|---|---|
| A0-1 | Сайт analog.com недоступен из среды разработки (обрыв TLS/503 на всех запросах). Даташит ADV7280 Rev. A, UG-637 Rev. A и AN-1260 Rev. 0 получены как **архивные копии оригинальных PDF с analog.com через web.archive.org** (`id_`-режим, байт-в-байт оригинал). Контрольные суммы записаны в `docs/requirements.md`. Копии с зеркал дистрибьюторов (Rev. 0 UG-637) удалены как более старые. | ACCEPTED (факт среды) |
| A0-2 | **I²C-адрес.** Overlay `adv7282m` (который включает `adv728x-m`) задаёт `reg = <0x21>` (7-битный адрес) = 8-битный адрес записи **0x42** = по даташиту **ALSB = 1 (лог. «1»)**. ТЗ требует ALSB на GND (0x40 write / 0x20 7-бит). Чтобы строка `dtoverlay=adv728x-m,adv7280m=1` работала **без параметра `addr=`**, ALSB должен быть подтянут к DVDDIO (3,3 В). Предложение: ALSB через перемычку (паяльную) — по умолчанию к 3,3 В (адрес 0x21), опционально на GND (0x20, тогда в config.txt нужно `addr=0x20`). | OPEN — нужно решение |
| A0-3 | **RESET / PWRDWN.** Overlay `adv7282m` **не задаёт** `reset-gpios` / `powerdown-gpios`, а драйвер `adv7180.c` получает их как *optional* (`devm_gpiod_get_optional`) — при их отсутствии драйвер ничего не дёргает и делает только программный сброс по I²C (рег. 0x0F[7]). Overlay также **не включает** регулятор `cam1_reg` (CAM_GPIO, пин 11 разъёма, GPIO-экспандер Pi 4 линия 5), поэтому уровень CAM_GPIO при загрузке с этим overlay не гарантирован (ядро отключает неиспользуемые регуляторы → скорее всего **низкий**). Следствие: чип должен выходить из reset и power-down **аппаратно, без участия Pi**: PWRDWN и RESET — подтяжки к 3,3 В (RESET — RC-цепь ≥ 5 мс по даташиту). Перемычки для подключения CAM_GPIO к PWRDWN (и/или RESET) — опция, по умолчанию разомкнуты. | OPEN — подтвердить |
| A0-4 | Питание 1,8 В: типовой ток 1,8 В-рельс ≈ 143 мА (AVDD 47 + DVDD 70 + PVDD 12 + MVDD 14), расчётный по UG-637 табл. 89 — 250 мА. При одном LDO в SOT-23-5 (AP2112K, θJA ≈ 250 °C/W) рассеивание (3,3−1,8)·0,143 = 0,21 Вт → +54 °C типично, до +94 °C при расчётном токе — на грани. UG-637 рекомендует раздельные регуляторы для AVDD/PVDD и цифры. Предложение: **два LDO** — AMS1117-1.8 (SOT-223, JLCPCB Basic) на DVDD+MVDD и малошумящий LDO (AP2112K-1.8 или ME6211C18) на AVDD+PVDD с ферритами. Альтернатива: один LDO в SOT-223 + ферритовые бусины. | OPEN — выбрать вариант |
| A0-5 | Разъём FFC на плате повторяет **разъём модуля камеры Raspberry Pi** (15 конт., шаг 1,0 мм, нижние контакты, на верхней стороне, у кромки, шлейф выходит наружу), нумерация 1:1 с J3 Pi (1 = GND … 15 = 3V3, подтверждено схемой Camera Module v2.1: J1 pin 3 = D0P, 9 = CLKP, 13 = SCL, 14 = SDA, 15 = 3V3). Предполагается стандартный 15-жильный шлейф камеры Pi (тот, что идёт с Camera Module). Нумерация выводов у разных производителей 15P/1.0 мм разъёмов может отличаться зеркально — **перед первым включением проверить мультиметром: 3,3 В должно приходить на пин 15, GND на пин 1**. | OPEN — подтвердить тип шлейфа |
| A0-6 | Используется только лента данных 0 (D0) и клок — `data-lanes = <1>` в overlay. Пины 5/6 (лента 1) разъёма оставляются неподключёнными. | ACCEPTED (следует из overlay) |
| A0-7 | Кварц: UG-637 и даташит не задают значения нагрузочных конденсаторов; используется методика AN-1260 (C = 2·(CL − CS) − CPG). Конкретный кварц выбирается из каталога JLCPCB на этапе 1, C1/C2 считаются под его CL (для CL = 30 пФ по AN-1260 → 47 пФ; для типового SMD-кварца CL = 18–20 пФ → ≈ 27–33 пФ). | ACCEPTED |
| A0-8 | Импеданс MIPI: предварительная оценка по формулам микрополоска для JLC04161H-7628 (h = 0,2104 мм, εr = 4,4): 100 Ω дифф ≈ 0,18–0,20 мм / зазор 0,15 мм. Финальные значения на этапе 3 сверяются с калькулятором JLCPCB. | ACCEPTED |
| A0-9 | KiCad 9.0.9 установлен из PPA `kicad/kicad-9.0-releases`; `kicad-cli sch erc` и `kicad-cli pcb drc` проверены на тестовых файлах. Стандартные библиотеки KiCad 9 (symbols/footprints) установлены. | ACCEPTED |
